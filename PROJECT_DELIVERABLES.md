The P02 ZIP includes editable Blender, STL/3MF/OBJ/MTL, registration SVG, previews, masks, coordinate contracts and manifests. Open the Blend in Blender; import a chosen 3MF into your slicer and assign opaque structure to extruder 1, transparent glazing/loops to extruder 2. Six tiles assemble the ground floor; both loops are on B2. Dimensions and plate placement were checked in software. Actual slicing, toolhead/purge clearance, print fit, glued assembly and hanging load remain untested. Two local geometry review JSON files containing personal machine paths were excluded; every retained producer file is byte-identical. The producer archive is preserved. ZIP SHA-256: `0328d97c1c321a9aa055568b97b10d97e36a2f834667a3df31320c83246b6b12` (15,041,064 bytes).

Quest is a Windows PC-VR overlay, not an Android build. Suitable Meta Link installation/account, cable, headset setup and the active OpenXR runtime are operator prerequisites; the launcher never installs software, switches runtime/registry, or changes security policy. Neither SteamVR nor UnrealEditor is required for this Quest target. Default VisualBaseline retains the producer's R29 settings; RTX2080 is explicit and process-only. Real Quest/Vive controllers, tracking, stereo, comfort, initial facing/recenter/height and sustained hardware performance remain untested. Inherited Research doorway obstruction and navigation limits remain. No tested build has been recooked or silently stripped of necessary assets.

Editable Unreal work uses the licensed original project and R29 source overlays described in their release notes; Quest's single input mapping delta is under `targets/quest3-pcvr-r01/QuestSourceDelta` and belongs in a separate Quest copy. Existing third-party dependency/licensing caveats remain in the earlier provenance notes; public sharing approval does not establish redistribution rights for third-party assets. The new P02 source audit found no linked libraries or embedded external photographs.
