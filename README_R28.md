## Run from GitHub Desktop

Select **main**, Fetch origin, Pull origin, then Repository > Show in Explorer. Run **Start_CampusCenter_Vive.cmd** or **Start_CampusCenter_Desktop.cmd** at the checkout root. The first run downloads, hashes, reconstructs and extracts the complete pinned R28 runtime; subsequent runs verify/reuse it. No GitHub token or Unreal editor is needed. Keep at least 12 GB free for Vive or 20 GB for desktop. Runtime files use a short gitignored `.cc/r28` directory; existing `.cc/r27r13` caches and R13 release assets are preserved. Paths with spaces work. Very deep paths are rejected before large downloads; move the checkout to a shorter folder if requested. No OS runtime, security or long-path settings are changed.

For Vive, install/start SteamVR and select it as the active OpenXR runtime, then connect your headset/controllers. Hold either trigger to walk in the headset's horizontal facing direction; release stops trigger-only walking. Protected turning, speed, keyboard coexistence, input focus/tracking behavior and collision remain unchanged. The producer-tested Vive bootstrap selects `/Game/Campus/Maps/CampusCenter_Vive_R27_R28_FinalReview_r01` with the inherited VR/plugin/fullscreen flags and 50% screen percentage/FPS display. Desktop bootstrap selects `/Game/Campus/Maps/CampusCenter_FA26_Desktop_R27_Enhancements_R28_LockerEastClearance`.

## Manual release downloads

Download every numbered part of your chosen `CampusCenter_Vive_R28_Windows.zip` or `CampusCenter_Desktop_R28_Windows.zip`, plus `ARCHIVE_MANIFEST.json` and `Reassemble-Downloads.ps1`, into one folder. Run `powershell -NoProfile -ExecutionPolicy Bypass -File .\Reassemble-Downloads.ps1`, then extract the resulting ZIP completely. Run `Windows/CampusCenter.exe` for either build. Keep the entire Engine and CampusCenter folders together. The joiner verifies part count, total size and final SHA-256. `SHA256SUMS.txt` and runtime manifests record exact public file bytes.

## Editable sources and reproducibility

`CampusCenter_R28_Cumulative_Sources.zip` contains each platform's cumulative R13 project-owned source/config/plugin overlay plus the 56 exact approved post-R13 native packages. Restore the appropriately licensed baseline from the [R13 release](https://github.com/mikeymcfish/CampusCenter/releases/tag/campuscenter-r27-r13-review-20261002) and its earlier v26/R25 source instructions; then overlay `desktop/project` or `vive/project` onto its corresponding Unreal project root. Use the documented UE 5.8 toolchain, retain each platform's separate configuration and compile the included CampusCrowdFix source if needed. Open the exact R28 map above. These are editable overlays, not standalone replacements for unredistributed Epic/MetaHuman/Fab/manufacturer dependencies or model weights. `SOURCE_MANIFEST.json` pins every overlay file. `NATIVE_DELTA_MANIFEST.json` records all 112 post-R13 package paths and hashes, including the 21 inherited Fitness dependencies per platform. The launcher code and pinned release manifest are on main; packaging only archives existing tested bytes and does not recook or rebuild them.
