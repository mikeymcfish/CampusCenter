# Optional P02 player projector companion + R29 sender R01

This separate Windows test target combines the sealed tracker with a small guarded native sender patch. Existing R29 desktop, Vive, Quest and performance launchers/defaults stay unchanged. No full game download is needed if the exact supported game is already prepared. This is Windows PC VR, not Quest standalone Android.

1. Fetch/pull current [CampusCenter main](https://github.com/mikeymcfish/CampusCenter). For Vive run `Start_CampusCenter_Vive.cmd -PrepareOnly`; use its managed `.cc\r29\v\g\Windows` folder. For Quest run `Start_CampusCenter_Quest3_USB_Link.cmd -PrepareOnly`; use `.cc\r29\q\w\Windows`. These existing hash-verified launchers fetch only missing published dependencies. Ordinary unpatched R29, older or unknown containers are refused. Required baseline native SHA256: `20adab2cd975e19d325adbe607b907cfffa2bd3e775b01c51a68f695bfdf915a`.
2. Extract the optional sender patch into a separate short folder. Choose a new empty destination outside the source. From the patch folder run `powershell.exe -NoProfile -File .\ProjectorSender.ps1 -Action Install -SourceWindows "<prepared Windows folder>" -TargetWindows "<new Windows folder>"`. Replace both placeholders with your absolute paths; keep the new target path below150characters. The installer validates original dependencies, reconstructs the native executable, adds the small OSC metadata overlay and verifies every hash. It preserves the source and refuses existing destinations. Quest support is retained only if the original verified Quest overlay is present.
3. Extract the portable companion ZIP into a writable folder. Keep `app`, `runtime` and launchers together. Double-click `Start_Tracker.cmd`; private .NET runtime/licenses are included, with no runtime installation. Stop the simulator before live use. The sealed companion archive retains its original software-stage README/QA; the newer live integration results below supersede its old sender-pending note.
4. In **Preview / calibration**, explicitly select the actual secondary projector and click **Open selected projector**. Primary display is refused; with one display, use the control preview. No output opens automatically. Use the unchanged **P02 whole sample at1:250**, approximately263.36x196.8mm, not the1:100/UV02 atlas assembly. Align outline/grid/L01-L10, adjust translation/scale/rotation and four corner controls; inspect Ground/Upstairs test poses. Choose sharp radius/blur sigma; **Save profile** persists `app/data/calibration.json`, **Load saved** restores without opening output, **Reset calibration** closes output and resets in memory (Save to persist). Physical alignment remains untested.
5. Select **LIVE telemetry**. In the newly installed game run `Start_Vive_Projector.cmd` or `Start_Quest_Projector.cmd`; these explicitly enable the loopback-only sender. Return focus to the game. Existing SteamVR/Meta Link/OpenXR environment remains an operator prerequisite; nothing is installed or switched. Quest patch requires the retained Quest overlay. Sender-disabled launch remains available with `ProjectorSender.ps1 -Action Launch -Mode Vive` without `-EnableSender`.
6. Ground dot is sharp; upstairs is Gaussian blurred at the same registered XY. Invalid/outside/missing game focus hides it;500ms stale telemetry hides it after the game stops. Fixed registration: `Xmm=(UE_Xcm+4700)/25`, `Ymm=(-UE_Ycm+230)/25`. OSC `/campuscenter/player/v1`, types `,issisfffffiii`,127.0.0.1:9001 only. Stop competing receivers/simulators.
7. To verify the installed copy run `ProjectorSender.ps1 -Action Verify` there. To roll back, close that exact game and run `ProjectorSender.ps1 -Action Rollback`; it verifies/restores the baseline and retires sender files into a preserved timestamped folder. Use the original game launcher afterward. Original source game and all root launchers stay available.
