# Consolidated R29 Vive launcher with verified GripTurn R01 / PublicGuard R02

Fetch and pull **main**, then run **Start_CampusCenter_Vive.cmd**. The normal launcher obtains/verifies the existing R29 runtime and the pinned 20 MB public grip patch. It creates a separate managed runtime in `.cc/r29/v/g`, applies the hash-guarded patch, checks the patched executable, all unchanged runtime files, three overlays and original backup, then starts the correct R29 Windows bootstrap. Repeat starts verify/reuse this patched runtime. Existing pristine or recognizable manually patched `.cc/r29/v/w` remains intact; unknown modifications stop consolidation for review. No multi-GB recook is performed. First preparation needs an additional roughly 4 GB for the managed runtime/backup; allow 20 GB total free for a fresh Vive installation.

Left/right side grips snap -30/+30 degrees once per distinct press. Release re-arms; simultaneous grips suppress rotation, focus/tracking loss requires neutral release and collision-aware head-pivot rotation is retained. Index-trigger forward remains unchanged. Starting yaw, SteamVR/OpenXR selection, maps, desktop, default rendering quality and runtime/system settings are unchanged. Actual headset operation, performance/freeze and initial-facing acceptance remain unverified.

Normal defaults are retained. To explicitly request the optional 3050 process-only profile, use `Start_CampusCenter_Vive.cmd -Profile RTX3050`. This uses the same verified managed grip runtime with the existing profile's reduced rendering arguments; it is not a confirmed headset/performance fix. `Start_CampusCenter_Desktop.cmd` retains its original R29 flow and quality.

`Start_CampusCenter_Vive.cmd -PrepareOnly` prepares/verifies without launch. `-VerifyOnly` checks an already prepared mode without downloads, installation or launch. Close CampusCenter before the first install, rollback or re-enable; no other game process will be stopped.

Rollback: `Start_CampusCenter_Vive.cmd -RollbackGripPatch` validates the current patch and original backup, restores the exact original executable, removes only its three overlays and records the original mode. It does not start the game. Subsequent normal launches respect that rollback. Re-enable using `Start_CampusCenter_Vive.cmd -EnableGripPatch` (add `-PrepareOnly` to avoid launch). Re-enable prepares a fresh verified managed copy and preserves the previous runtime/rollback folder. Interrupted staging is preserved; unknown/tampered runtimes and backups refuse installation/launch. Game Saved/config folders are copied locally when switching managed runtimes so existing saved settings are retained.

The public R29 runtime archives and the small [manual grip patch release](https://github.com/mikeymcfish/CampusCenter/releases/tag/campuscenter-vive-grip-turn-r01-publicguard-r02-20261004) remain immutable. Manual `Start_Patched_CampusCenter_Vive.cmd` / matching 3050 CMDs inside Windows still work. Older root launcher commits cannot retain manual patches; fetch/pull current main to use this integrated flow. `patches/vive-grip-turn-r01/project` contains the five tested editable native/C++ changes to overlay onto the matching licensed Vive source baseline. Frozen `r29` sources/builds and original release history remain preserved. `optional-launchers/rtx3050` contains the explicit optional scripts and profile details.
