# Quest 3 PC-VR R01

After fetching/pulling current main, run **Start_CampusCenter_Quest3_USB_Link.cmd**. It verifies the small Quest package and prepares a separate R29 grip-enabled prerequisite cache `.cc/r29/qb`, reusing only hash-verified immutable downloads when available. It then installs the one-package Touch mapping overlay into a separate `.cc/r29/q/w/Windows` runtime. Existing Vive `.cc/r29/v` and desktop caches/source/settings are preserved, even if the Vive grip update was rolled back. No manual patch juggling or Unreal editor is required. Allow roughly 20 GB free for a fresh target. Close CampusCenter before its first prerequisite grip installation; no processes are stopped automatically.

This is Windows **PC-VR over USB Link**, not an Android standalone build. The operator must already have suitable Meta Quest Link software/account/headset setup, a working USB data connection and the desired active Windows OpenXR runtime. Enter Link before launch. SteamVR and UnrealEditor are not required. This launcher never installs Meta software, changes the OpenXR registry/runtime, configures accounts, recenters the headset or forces refresh rate. Touch profile negotiation and hardware performance are unverified. PowerShell runs under the existing execution policy; if downloaded scripts are blocked, stop and review with the operator rather than changing policy automatically.

Default `VisualBaseline` keeps the producer's existing R29 visual settings. Explicit optional **`Start_CampusCenter_Quest3_USB_Link.cmd -Profile RTX2080`** requests the tested process-only RTX2080 settings; neither mode changes Vive/desktop default quality or saved project settings. The Meta/runtime operator still controls headset refresh/resolution/encoding. The requested pixel density, 72 Hz suggestion and sustained frame budget have not been validated on real hardware. `-Diagnostic` enables the producer's concise control edge/yaw diagnostics.

Touch index triggers retain forward walking. Left/right analog side grips snap -30/+30 degrees once per squeeze, with inherited release rearm, simultaneous-grip suppression, focus/tracking safety and collision-aware head pivot. Four Touch analog mappings are added while all six Vive mappings remain. Architecture, materials, effects, lights, native executable, maps and starting yaw are unchanged. No blind 180-degree yaw flip is applied.

Use `-PrepareOnly` for installation/verification without launch and `-VerifyOnly` for an existing installation without writes/downloads. `-RollbackQuest` validates then retires only the three Quest overlay containers and install identity, disables the root Quest launch flow and leaves all Vive/desktop/base files intact. `-EnableQuest -PrepareOnly` preserves the retired Quest copy and installs into a fresh isolated target. Unknown file/hash changes refuse update and launch. Interrupted copies remain preserved for review. The source delta is under `targets/quest3-pcvr-r01/QuestSourceDelta`; apply it only to an appropriately licensed Quest-specific copy of the R29/grip baseline, never to the canonical Vive mapping context.

The producer tested 29 software input cases, both packaged profiles, install/refusal and rollback. The publisher checks these against the actual public R29/grip pins and tests repeat root launch/rollback. Link, Quest3, Touch controllers, RTX2080 performance, comfort, real tracking/focus/head pivot/collision, initial facing/recenter/height and sustained frame timing still need physical acceptance. No complete hardware-ready claim is made.
