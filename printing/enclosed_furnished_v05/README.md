# Campus Center — standalone furnished projection prints v05

Two separate levels; six printable tiles per level. Originals remain unchanged.

- [Ground floor](ground/README.md): solid exterior enclosure around the furnished ground model.
- [Upper floor](upper/README.md): furnished rooms and fitness area, low terrace/bridge parapets, open atriums; no single-storey roof patch.

Each folder includes STEP, STL, assembly and individual 3MF files, a tile diagram, an isolated Blender print model, calibrated masks, and its own 42-second informational animation.

Both use 1:87.5 scale and the same new 830 x 637.08984375 mm overhead projection canvas. These are standalone floor displays, not the old stackable model. Read each floor's printing and calibration notes before use.
