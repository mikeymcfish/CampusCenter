# Ground-floor LEGO study model

Start with `Campus_Center_LEGO_Build_Guide.pdf`. This 35-page guide includes baseplate coordinates, four wall courses, detailed stud maps, door lintels and simple interior blocks.

- 662 pieces, including six 32 x 32 baseplates.
- 96 x 64 studs overall (76.8 x 51.2 cm).
- Approximately 1:125 horizontally; walls are four bricks high for an open-top study model.
- Black structure, white glazing representation, tan tables and gray seats/equipment.
- 29 simplified door openings; closely spaced openings and small plan offsets are merged or omitted at this grid size.

`parts_list.csv` is the exact material/color count. `brick_placements.csv` gives every piece's southwest stud coordinate, course, width and depth. `Campus_Center_Ground_Floor.ldr` is an editable standard-parts LDraw model; use a compatible editor with its parts library installed. `LEGO_Assembly_Preview.blend` is a schematic blocks-and-studs preview.

All bricks were checked for same-course overlap and support from a stud below. Lintels span the doorway with support at both ends. No physical LEGO build has been tested. Keep the six baseplates on a flat board when moving the model.
